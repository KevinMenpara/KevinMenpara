### Work I'm proud of

- **Error-resolving system, Improwised Technology (2024).** An LLM-powered system that diagnoses Kubernetes infrastructure errors: Robusta alerts flow through a message queue to Python workers, Outlines structures the prompts, and an LLM proxy routes them to Llama. Errors were resolved 34% faster, and the queue made the system 70% more reliable. [Case study](https://kevinmenpara.github.io/portfolio/work/ers/)
- **RITAAwards, Rovren Technology (2023).** Registration and verification platform for an IT industry association's awards, used by 1,000+ people. Built on ToolJet, PostgreSQL, PostgREST and AWS S3, with AES-256 encryption for applicant data. [Case study](https://kevinmenpara.github.io/portfolio/work/rita-awards/)
- **GeoPanap (2023).** Land-lease and environmental-compliance platform for a semi-government agency: customers, leases, minerals, clearances and pollution-control records with expiry tracking. PostgreSQL with versioned migrations, PostgREST, ToolJet and S3. [Case study](https://kevinmenpara.github.io/portfolio/work/geopanap/)
